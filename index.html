AI 智能体

多端联动

开启 Tool Server 后在局域网广播服务，手机端发现配对即可远程调用记账工具，让 iOS 上的 AI 助手拥有电脑端的数据能力。

≋

账单导入

支付宝 CSV 与微信账单 XLSX 草稿式导入：解析、分类映射、明细复核、一键入库，按交易号自动去重。

◌

语音记账

Whisper 本地语音识别，离线也可用。说一句「昨天打车花了 35」，账就记好了。

✉

微信渠道

扫码登录后，微信消息直达智能体，随手发一句就能记一笔、查一账。

◈

账目体系

账户、收支分类（二级）、预算与报表图表，金额精确到分，流水软删除可追溯，账目清晰又安心。

笔笔 · 桌面端
  • Tool Server：Express HTTP（端口 19878）+ Bonjour 广播（_bibi-tools._tcp）
  • 6 位配对码认证（300 秒有效），Bearer Token 鉴权
  • 动态导出已启用 Skill 的工具清单（含 JSON Schema）
  • 配对设备管理：查看与撤销
⇄ 局域网 Bonjour 发现 · 配对 · HTTP 调用

  • NetServiceBrowser 自动发现电脑

  • 工具列表合并进智能体 function calling
  • 断线自动重连，支持手动 IP 直连
