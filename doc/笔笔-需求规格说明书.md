## 1. 产品概述

### 1.1 产品定位

一款纯本地的 Windows 桌面端个人记账软件。打开即用、离线运行、数据完全由用户掌控。

### 1.2 目标用户

- **个人用户**：管理自己的日常收支
- **家庭用户**：多人在同一台电脑上分别记账，数据完全隔离

### 1.3 核心原则

| 原则     | 说明                                  |
| -------- | ------------------------------------- |
| 离线运行 | 不请求任何网络接口，数据不离开本机    |
| 零配置   | 安装后直接使用，无需注册/登录/联网    |
| 快速响应 | 启动 ≤2 秒，保存记账 ≤200ms           |
| 数据安全 | SQLite 本地存储，用户完全掌控数据文件 |

## 2. 整体架构

### 2.1 功能模块总览

```
笔笔
├── 2.1 用户管理
├── 2.2 记账（核心模块）
├── 2.3 账户管理
├── 2.4 分类管理
├── 2.5 流水查询
├── 2.6 预算管理
├── 2.7 数据导入
└── 2.8 统计概览
```

### 2.2 多用户数据隔离方案

每个用户拥有完全独立的数据集，通过 SQLite 的 `user_id` 字段隔离。

```
用户A ─── 账户表（user_id=A）
    ├── 流水表（user_id=A）
    ├── 分类表（user_id=A）
    └── 预算表（user_id=A）

用户B ─── 账户表（user_id=B）
    ├── 流水表（user_id=B）
    ├── 分类表（user_id=B）
    └── 预算表（user_id=B）
```

切换用户时，所有界面数据瞬间切换，无需退出确认。

### 3.2 记账

#### 3.2.1 账目数据模型

| 字段         | 类型          | 说明                   |
| ------------ | ------------- | ---------------------- |
| 流水 ID      | UUID          | 自动生成               |
| 用户 ID      | String        | 所属用户               |
| 类型         | Enum          | 支出 / 收入 / 转账     |
| 账户 ID      | String        | 关联的账户             |
| 目标账户 ID  | String        | 转账时必填             |
| 分类 ID      | String        | 关联的一级分类         |
| 子分类 ID    | String        | 关联的二级分类（可选） |
| 金额         | Decimal(12,2) | 支持两位小数           |
| 日期         | Date          | 默认当天               |
| 备注         | String(200)   | 可选                   |
| 创建时间     | DateTime      | 自动记录               |
| 最后修改时间 | DateTime      | 自动记录               |

#### 3.2.2 功能列表

| 编号  | 功能     | 说明                                                        | 优先级 |
| ----- | -------- | ----------------------------------------------------------- | ------ |
| BK-01 | 记支出   | 选择账户 → 选择分类 → 输入金额 → 可选填写备注 → 保存        | P0     |
| BK-02 | 记收入   | 切换到收入页签，流程同上                                    | P0     |
| BK-03 | 转账     | 选择转出账户 → 转入账户 → 输入金额 → 保存，自动生成两条流水 | P0     |
| BK-04 | 编辑流水 | 修改任意已保存账目的字段                                    | P0     |
| BK-05 | 删除流水 | 删除单条流水，需二次确认；转账流水两条同时删除              | P0     |
| BK-06 | 连续记账 | 保存后自动保留分类和账户，清空金额，方便连续记账            | P1     |
| BK-07 | 默认账户 | 记账时自动选中用户设定的默认账户                            | P1     |

#### 3.2.3 记账交互原则

- 默认进入支出模式，因为支出场景远多于收入
- 金额输入框获得焦点时自动选中已有内容，方便直接覆盖
- 分类选择时支持拼音首字母搜索
- 保存成功后不关闭界面，继续记下一笔

| 编号  | 功能         | 说明                                                    | 优先级 |

- 未设定预算的分类不展示进度

## 5. 数据存储方案

| 项目     | 方案                                   |
| -------- | -------------------------------------- |
| 数据库   | SQLite                                 |
| 存储位置 | 默认 `%APPDATA%/笔笔/`，支持用户自定义 |
| 用户隔离 | 所有表携带 `user_id` 字段进行数据隔离  |
| 备份方式 | 直接拷贝数据库文件即可完成备份         |
| 恢复方式 | 替换数据库文件后重启软件               |
| 无网络   | 完全离线，零网络请求                   |
