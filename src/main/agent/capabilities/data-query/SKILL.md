# 数据查询 Skill

本 Skill 为原子型，工具可直接调用，无需先 getSkill。

## 使用规则

1. 所有查询自动限制在当前用户范围内，不传用户 ID。
2. 优先选择最精确的查询工具，避免拉取冗余数据。
3. 金额单位为“分”，展示给用户时换算为“元”。
4. 查询结果为空时友好提示“该时间段没有记录”或“分类下暂无数据”。
5. 涉及百分比变化或数值对比时，使用 [数学计算] 能力域的工具计算，不口算。
