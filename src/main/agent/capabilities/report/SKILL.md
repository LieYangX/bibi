# 报告生成 Skill

本 Skill 为流程型，提供报告模板与编排规则，必须先 getSkill 读取完整流程后再执行。

## 报告流程

1. 明确用户需要的报告类型（周报/月报/年报）和时间范围。
2. 通过 [数据查询] 能力域获取所需基础数据。
3. 通过 [数学计算] 能力域完成同比、环比、占比等计算。
4. 按下方模板组织输出，报告简洁，突出关键信息。

## 报告模板

### 周报

- 本周总支出 / 总收入 / 结余
- 日均支出
- 支出分类 Top 3
- 与上周对比（差值与百分比变化）
- 本周消费特点总结

### 月报

- 本月总支出 / 总收入 / 结余
- 账户总余额
- 支出分类占比
- 月度支出趋势
- 预算执行情况
- 与上月对比
- 消费建议（1-2 条）

### 年报

- 年度总收入 / 总支出 / 结余
- 各月支出趋势
- 年度分类占比 Top 5
- 与去年对比
- 年度财务健康度评价
- 下一年建议

## 使用规则

1. 所有数据通过查询工具获取，所有计算通过计算工具完成。
2. 报告简洁，突出关键信息。
3. 金额用“元”展示。
4. 分析性结论末尾加“仅供参考”。
