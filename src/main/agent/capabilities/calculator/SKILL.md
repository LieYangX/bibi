# 计算器 Skill

LLM 自身数学计算不可靠，所有计算必须通过以下工具完成。

## 可用工具

| 工具               | 用途                                                        |
| ------------------ | ----------------------------------------------------------- |
| evaluate           | 执行数学表达式（支持 + - * / % ^ 和括号），如 “1500 + 3200” |
| summarize          | 对一组数值汇总统计（总和、平均值、最大值、最小值、数量）    |
| compareValues      | 对比两个数值，返回差值、变化百分比和趋势描述                |
| convertCentsToYuan | 将“分”转换为“元”（1元=100分），返回 ¥ 格式字符串            |

## 使用规则

1. 任何计算都通过工具完成，不依赖自身数学能力
2. 多步计算拆分步骤，逐步调用合适工具
3. 涉及百分比变化使用 compareValues，不口算
4. 从数据库查到的分值先用 convertCentsToYuan 换算为元
