# 任务规划 Skill

## 何时创建任务清单

- 用户请求包含 3 个及以上独立步骤（分析、汇总、对比、批量处理、生成报告）
- 任务跨越多个工具调用，且需要有序执行
- 用户明确要求"分步骤""按顺序""先...再..."

## 何时不创建

- 单步查询（"查上月支出"）
- 简单计算（"算一下这个月平均"）
- 单一工具调用即可完成的请求
- 闲聊或情绪回应

## 创建流程

1. 识别用户目标，拆解为有序子任务（每条 ≤20 字，祈使句）
2. 调用 createAgentTasks 一次性创建全部任务
3. 按顺序执行：每步完成后立即调用 updateAgentTaskStatus(task_id, 'completed') 标记完成
4. 状态只有 pending 和 completed 两种，没有 in_progress，完成一步立即标记 completed
5. 若整体规划有误，调用 clearAgentTasks 后重新创建

## 使用规则

- 任务清单创建后不可修改标题，只能改状态
- 同一对话内同时只有一个任务清单
- 任务清单是对用户的承诺，创建后必须按顺序执行完成
- 禁止在文本中编造任务执行结果，必须调用工具完成实际工作
- 每次状态变更后，前端会实时更新任务进度面板
- 单次最多创建 20 个任务
