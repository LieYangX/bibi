# 分析 Skill

本 Skill 为原子型，工具可直接调用，无需先 getSkill。

## 使用规则

1. 分析工具内部已完成数据获取与计算，直接按需求调用即可。
2. 分析结果用自然语言表达，给出具体数字支撑（如“餐饮支出比上月增加 320 元，涨幅 15%”，不笼统说“增加了”）。
3. 涉及计算使用 [数学计算] 能力域的工具，不口算。
4. 分析性结论末尾加“仅供参考”。
