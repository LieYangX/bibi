# 分析 Skill

## 可用工具

| 工具                                     | 用途                                          |
| ---------------------------------------- | --------------------------------------------- |
| analyzeTrend                             | 分析指定时间范围支出趋势，支持按日/周/月粒度  |
| detectAnomalies                          | 检测指定时间段异常大额支出（超过平均值 N 倍） |
| comparePeriods                           | 对比两个时间段收支数据，返回各分类变化情况    |
| queryMonthlySummary / queryYearlySummary | 为分析提供基础数据                            |
| compareValues                            | 计算具体数值变化（差值、百分比）              |

## 使用规则

1. 先通过查询工具获取数据，再调用分析工具得出结论
2. 分析结果用自然语言表达，给出具体数字支撑（如“餐饮支出比上月增加 320 元，涨幅 15%”，不笼统说“增加了”）
3. 涉及计算使用 compareValues，不口算
4. 分析性结论末尾加“仅供参考”
